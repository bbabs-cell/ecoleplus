# Roadmap EcolePlus

Ne pas passer à la phase suivante tant que la phase courante n'est pas stable (typecheck/lint/build OK, tests critiques passants, RLS vérifiée).

- **Phase 0 — Inspection & architecture** : inspection complète (`/inspect`), rapport, modèle de données initial, plan de migrations, plan de sécurité, backlog priorisé.
- **Phase 1 — Fondation SaaS** : init Next.js/TS, Supabase, auth, organisations, établissements, utilisateurs, rôles, permissions, RLS, audit, layout/navigation, paramètres de base.
- **Phase 2 — Gestion académique** : années académiques, niveaux, classes, groupes, enseignants, matières, apprenants, inscriptions, affectations.
- **Phase 3 — Présences & notation** : sessions de présence, absences/retards/justificatifs, évaluations, saisie notes, systèmes de notation configurables, calculs, validation, bulletins.
- **Phase 4 — Finances** : frais, échéances, paiements manuels, soldes, reçus, historique, permissions financières.
- **Phase 5 — Fichiers & stabilisation** : Cloudflare R2, documents privés, bulletins/reçus, traductions, RTL, responsive complet, tests, corrections sécurité, préprod, documentation.
- **Phase 6 — Extensions** : portails parents/apprenants, communication, transport, bibliothèque, RH/salaires, emploi du temps, paiements en ligne, abonnements SaaS, fonctions universitaires avancées, reporting avancé.
